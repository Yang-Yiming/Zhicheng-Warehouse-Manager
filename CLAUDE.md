# Warehouse manager - miniprogram ver

This project tries to turn an old python project into wechat-miniprogram.

- For wechat-miniprogram development, relavent docs are in `./related-docs.md`
- The old python project is in `./old_python`

# Tooling Preferences

- Prefer **miniprogram-ci** for upload/preview/build tasks over the WeChat DevTools GUI
- Docs: https://developers.weixin.qq.com/miniprogram/dev/devtools/ci.html
